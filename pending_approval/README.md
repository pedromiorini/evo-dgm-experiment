# Aprovações pendentes

Esta pasta contém decisões que exigem aprovação humana antes de alterar segurança, validade, causalidade, interpretabilidade, dependências, permissões, sandbox, evaluator, métricas, holdout, protocolo, threat model, orçamento ou provedor/modelo LLM.

Nenhum arquivo nesta pasta representa aprovação. Uma decisão só pode ser considerada aprovada quando houver responsável, data, justificativa, escopo e revisão/commit identificáveis.

O registro atual está em [DECISOES_HUMANAS.md](../protocol/DECISOES_HUMANAS.md).
